## 결정

- (스펙 승계) 최근 업로드 = RecentUploadsStorage 파일 최신순 6장, 비면 섹션 숨김.
- (스펙 승계) 캐싱·프리페치 제외 — 셀 크기 targetSize 요청만.
- 일부허용 재선택은 `presentLimitedLibraryPicker(from:)` **async 오버로드**로 호출 — 플랜의 completionHandler 대신. 콜백 신규 도입 금지 컨벤션에 맞고, Store 가 `limitedPickerTask` 핸들을 들고 `.disappeared` 에서 취소할 수 있다 (mvi.md 부수효과 규칙).
- `import PhotosUI` 추가 — `presentLimitedLibraryPicker` 는 Photos 가 아니라 PhotosUI 의 PHPhotoLibrary 카테고리다.
- Swift 6 격리 우회 없음 — `enumerateObjects`·`withCheckedContinuation`·`Task` 모두 MainActor 상속으로 무경고 통과. UIKit 별도 import 도 불필요(SwiftUI 재수출).
- `// TODO(#54)` 는 swiftlint `todo` 경고 1건을 남긴다 — 레포에 이미 같은 패턴 6건이 있어 그대로 둠 (캔버스 연결이 스코프 외라 표식이 필요).

## 검증 후 수정 (메인 세션, orca-cli 시뮬레이터 검증에서 발견)

- **갱신 누락**: 첫 권한 요청에서 "접근 제한"을 고르면 시스템이 선택 시트를 자동으로 띄우는데 종료 훅이 없어 선택 결과가 그리드에 반영 안 됨 → `PHPhotoLibraryChangeObserver`(릴레이 객체) 등록으로 근본 수정. 재선택·설정 변경·사진 추가 전부 커버.
- **재선택 크래시**: `presentLimitedLibraryPicker` 탭 시 `unrecognized selector` SIGABRT. 원인 = PhotosUI 가 ObjC 카테고리뿐이라 심볼 참조가 없어 **auto-link 누락**(바이너리에 Photos 만 링크됨) → `Package.swift` CanvasFeature 타깃에 `.linkedFramework("PhotosUI")` 명시.
- **최근 업로드 셀 이미지 로드 실패**: `fileURL.path()` 가 percent-encoding 기본이라 "Application Support" 공백에서 파일을 못 찾음 → `Data(contentsOf:)` 로 직접 로드. 렌더 경로도 AsyncImage → 기기 사진 셀과 같은 `Image(uiImage:)` 로 통일.
- `PHPhotoLibraryPreventsAutomaticLimitedAccessAlert` 키 추가 — limited 매 실행마다 뜨는 시스템 얼럿 억제(재선택 진입점은 우리 버튼). **시뮬레이터는 이 키를 무시하고 얼럿을 계속 띄움** — 실기기에서 억제 여부 확인 필요.

## 검증 (orca-cli 시뮬레이터, 2026-07-30)

- 미결정 → "접근 제한" 선택 → 선택 2장이 날짜 헤더("Jun 2 (Tue)"·"Jun 1 (Mon)")와 3열 그리드로 표시, "사진 재선택" 버튼 노출. ✅
- "사진 재선택" 탭 → limited picker 표시(기존 선택 유지), 1장 추가 후 확인 → 복귀 즉시 3장으로 갱신(observer). ✅
- 전체허용 → 전체 31장 날짜별 그리드, "사진 재선택" 버튼 미노출. ✅
